# Myolve Lab

システムエンジニア tmp のポートフォリオサイトです。
便宜上システムエンジニアとしていますが、ハードウェアの設計も行います。

**公開先:** https://piyopiyo...

## 概要

依存関係のない単一の HTML ファイルで構成しています。`index.html` を編集して push すると、GitHub Pages に反映されます。

- `index.html` — サイト本体（CSS を含む）
- フォントは Google Fonts（Sora / Noto Sans JP）を CDN から読み込み

## ローカルで確認する

ブラウザで `index.html` を直接開くか、簡易サーバを起動します。

```
python3 -m http.server 8000
```

## 対応領域

- 数理最適化モデルの設計・実装（Python / PuLP）
- 筋電計測・データ解析
- 回路・基板・筐体の設計と製造手配（Fusion 360 / JLCPCB）
- 生体信号デバイスの試作（BLE / Flutter）
